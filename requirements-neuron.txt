# App-layer Python dependencies for AWS Trainium (Neuron) training.
#
# IMPORTANT: this file deliberately does NOT list the packages that the Neuron
# stack owns. setup_neuron.sh installs `optimum-neuron[neuronx]` FIRST, which
# pins a mutually-compatible set:
#       torch (Neuron build)  torch-neuronx  neuronx-cc  libneuronxla
#       torch_xla  transformers  accelerate  tokenizers  huggingface_hub  safetensors
# Re-listing any of those here (especially with a hard ==pin) would let pip
# overwrite the Neuron-pinned versions and pull a CUDA torch — which is exactly
# the failure we hit before. So they are intentionally omitted.
#
# Differences vs requirements.txt (CUDA):
#   - REMOVED  bitsandbytes / transformer_engine / optimum-quanto  (CUDA-only)
#   - REMOVED  flash-attn                                          (Neuron uses SDPA)
#   - REMOVED  torch / transformers / accelerate / huggingface_hub / safetensors
#              (managed by optimum-neuron[neuronx])
#
# setup_neuron.sh installs this with --no-deps to protect the Neuron stack, then
# backfills the small set of pure-python transitive deps these need.
